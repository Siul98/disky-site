# Stackable Glass (Bento surfaces)

[Stackable Glass](https://app.spline.design/community/file/12c88eab-fad8-4360-bf1d-1c951436188d) by [Spline Team](https://app.spline.design/@spline), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Original interactive export retrieved 2026-09-08: https://prod.spline.design/TwDbT1tAvjU314kK-9q5/scene.hanacode . Saved locally as `../vendor/hana/stackable-glass.hanacode`.

Adaptations: one pane per Bento, resized/repositioned with responsive corners; removed stack, cursor tracking and demonstration backdrop. Original fill and three material effects retained. The DISKY studio-room backdrop is supplied behind the panes. One temporary Hana render produces all card surfaces, which remain static until their composition refreshes. Native HTML content stays separate and accessible.

The local Hana runtime additionally exposes its schema validator and an image-decode completion promise so snapshot rendering can finish deterministically without a permanent animation loop. Original material shaders are unchanged.

Original Spline Hana viewer 1.2.54 and hana-notext.wasm are bundled locally. Native website text and controls remain separate. The website uses the same material adapter as the app; its backdrop is a still of the DISKY studio room.
