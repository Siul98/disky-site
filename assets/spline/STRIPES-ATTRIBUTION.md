# Retrofuturism — DISKY blue adaptation

**Retrofuturism – BG animation** by **Design Gabor (DesignGabor)**.

Original: https://app.spline.design/community/file/fba5a24b-a843-461d-b983-e5c140313420

License: Creative Commons Attribution 4.0 — https://creativecommons.org/licenses/by/4.0/

The original public Spline scene geometry, glass material layers, cylinder cloner and
start transitions are used in this adaptation. Changes: removed reference copy and
logo objects, changed the light gradient to DISKY blue, disabled zoom, fitted the
scene to the top hero and added a static reduced-motion version. The original
scene texture is retained. The separate foreground cards use Spline Team's approved
Stackable Glass material.

Renderer: @splinetool/runtime 2.0.43 (WebGL standalone), distributed unmodified.
https://www.npmjs.com/package/@splinetool/runtime

The How section retains the earlier lightweight Canvas 2D reconstruction inspired
by the same reference; it is not the original scene.
